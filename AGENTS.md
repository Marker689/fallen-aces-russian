# AGENTS.md — Fallen Aces Russian Localization

Проект: русификация игры **Fallen Aces** (Unity-игра, нуар-детектив 90-х).
Рабочая директория: `~/fallenaces-rus/`.

## Цель
Перевести весь текстовый (нарративный) контент игры на русский язык, сохранив
нуар-тон, и распространять как мод/замену файлов.

## Ключевые факты об игре (проверено)
- Игра — **Unity** с кастомным слоем данных в открытых **текстовых файлах**.
- Текстовый контент лежит в `AcesData/` (на Windows:
  `C:\Program Files (x86)\Steam\steamapps\common\Fallen Aces\AcesData`).
- **Форматы строк** (критично для парсера):
  - Субтитры: `{ T 0.5 } "text"`, `T 0 "text"` (внутри `I N {}` блоков), просто `"text"`.
  - Записки: `text = "..."` (с rich-text тегами `<color=#...>`).
  - Скрипты: `SpeakDialogue(arg, "text")`, прочие вызовы с `"text"`.
- **Имена файлов менять НЕЛЬЗЯ** — `SpeakDialogue("...")` ссылается на субтитры
  по имени файла.
- **Кодировка: UTF-8 без BOM.**
- Число строк в файле менять нельзя.
- Кириллица в шрифтах есть (LiberationSans, aline_font).

## Моддинг / Workshop
- Мод = папка, повторяющая структуру `AcesData` (Subtitles/, Episodes/, ...).
- Загрузка в Workshop через `Tools\Lead Pipe\Lead Pipe.exe`.
- **ВАЖНО**: мод-система переопределяет Audio/Episodes/Texture Packages/Sprites,
  но **НЕ Subtitles**. Субтитры работают только при прямой замене файлов в
  `AcesData/Subtitles`. См. `notes/workshop-mod.md`.

## Конвейер (tools/)
- `extract.py` — извлечение всех строк (subtitle/episode/root) в `strings.json`.
- `extract_subtitles.py` — извлечение строк субтитров в `subtitle_strings.json`.
- `make_packs.py` — деление на батчи для параллельного перевода → `packs/batch_*.in.json`.
- `inject.py` — сборка мод-папки из оригиналов (бэкап) + переводов → `mod/`.
- `verify.py` — проверка целостности (кодировка, синтаксис, полнота).
- Исходники оригиналов для инжекта: бэкап `Fallen Aces_backup_txt` (НЕ AcesData,
  т.к. она может быть изменена пилотом).

## Глоссарий
`glossary/glossary.md` — «библия перевода»: имена, фракции, локации, сленг.
Все субагенты-переводчики ОБЯЗАНЫ следовать ему.

## Распространение
Пользователь оформляет всё как руководство / репозиторий GitHub (не установочный
скрипт). Репо должно содержать: переведённые файлы (структура `mod/`), README с
инструкцией по установке (прямая замена в `AcesData`, т.к. мод не переопределяет
субтитры), глоссарий, инструменты конвейера.

## Правила работы
- Массовый перевод — параллельными субагентами/team mode (по категории writing).
- Каждый переводчик получает глоссарий + свой `.in.json`, пишет в `.out.json`.
- Инжектор меняет ТОЛЬКО текст внутри кавычек (prefix + '"' + RU + '"' + suffix).
