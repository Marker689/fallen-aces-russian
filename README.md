# Fallen Aces — Русская локализация (русификатор)

Фанатский перевод текстового (нарративного) контента игры **Fallen Aces** на
русский язык. Игра — нуар-детектив 90-х с грубоватым стилем, иронией и чёрным
юмором; перевод старается сохранить этот тон.

> **Важно:** весь перевод выполнен **искусственным интеллектом (ИИ)** — это
> качественный черновик, а не выверенная человеком локализация. Перевод требует
> **ручной вычитки и правок** сообществом. См. раздел «Как помочь улучшить».

Непереведённое меню/UI — это строки, зашитые в скомпилированные DLL и
Addressables-ассеты. При желании их можно перевести позже (например через
XUnity.AutoTranslator), но основная нарративная часть уже покрыта.

## Установка

> **Критично:** мод-система игры (Aces Mod Manager / Steam Workshop)
> переопределяет Audio, Episodes, Texture Packages и Sprites, но **НЕ субтитры**.
> Поэтому перевод текста ставится **прямой заменой файлов** в папку игры.

### Способ 1 — ручная замена (рекомендуется)
1. **Скачай архив** со страницы релизов (готовый zip):
   [github.com/Marker689/fallen-aces-russian/releases](https://github.com/Marker689/fallen-aces-russian/releases)
2. Открой папку игры:
   ```
   C:\Program Files (x86)\Steam\steamapps\common\Fallen Aces
   ```
3. **Сделай резервную копию** папки `AcesData` (или хотя бы `AcesData\Subtitles`
   и `AcesData\Episodes`) — это позволит откатить перевод.
4. Скопируй содержимое папки `mod/` из этого репозитория **внутрь** `AcesData/`,
   соглашаясь на замену файлов.

   Итоговая структура должна выглядеть так:
   ```
   Fallen Aces\AcesData\Subtitles\...   (переведённые субтитры)
   Fallen Aces\AcesData\Episodes\...    (переведённые записки/главы)
   Fallen Aces\AcesData\loadingScreenTips.txt   (переведённые советы)
   Fallen Aces\AcesData\props.txt, consumables.txt, ...   (переведённые названия)
   ```
5. Запусти игру.

### Откат
Восстанови папку `AcesData` из резервной копии (п.2) — и перевод будет удалён.

## Как помочь улучшить перевод

Поскольку перевод сделан ИИ, **главная ценность — это ручная вычитка**.
Ты можешь помочь несколькими способами:

### 1. Сообщить об ошибке (проще всего)
Найди в игре некорректный, корявый или нестилистический перевод и открой
**issue** на GitHub. Укажи:
- где именно встретился текст (глава, записка, диалог, совет);
- как выглядит проблемный русский текст;
- что, по-твоему, должно быть вместо него (и почему).

### 2. Предложить правку через Pull Request
Ты можешь отредактировать любой файл в папке `mod/` и отправить PR.

- **Файлы субтитров** лежат в `mod/Subtitles/<Персонаж>/<Название>.txt`.
- **Записки** — в `mod/Episodes/<Эпизод>/<Глава>/Notes/<Файл>.txt`.
- **Названия глав** — в `mod/Episodes/<Эпизод>/<Глава>/chapterInfo.txt`.

**Правила правки (обязательно соблюдать!):**
- Переводи/правишь **только текст внутри кавычек** `"..."`.
- **Не меняй** тайминги (`T 0.5`), номера блоков (`I 0`), скобки и точки с запятой.
- **Не меняй** имена файлов — на них ссылается `SpeakDialogue("...")`.
- **Сохраняй** rich-text теги (`<color=#FFFFFF>`, `</color>`, `<br>`) и переносы строк.
- **Кодировка файлов — UTF-8 без BOM** (не UTF-8 с BOM, не ANSI).
- **Не добавляй и не удаляй строки** в файле.
- Старайся не превышать длину оригинала более чем в ~1.5 раза (важно для
  таймингов субтитров и вёрстки записок).

### 3. Согласованность терминологии
Перед правкой сверяйся с **`glossary/glossary.md`** — это «библия перевода».
В ней зафиксированы русские варианты имён персонажей, фракций, локаций и
сленга (например: Glassjaw → Гласджо, VISE → ВАЙЗ, Glasshearts → Глассхарты,
gumshoe → легавый). Это нужно, чтобы один персонаж не назывался по-разному
в разных файлах.

Если считаешь, что какой-то термин в глоссарии переведён неудачно — предложи
правку глоссария отдельным PR (это лучше, чем расходиться с глоссарием).

## Структура репозитория

```
mod/                 — готовые переведённые файлы (копируются в AcesData)
  Subtitles/         — переведённые субтитры (по персонажам)
  Episodes/          — переведённые записки, названия глав, эпизодов
  loadingScreenTips.txt, props.txt, consumables.txt, ...  — переведённые корневые файлы
tools/               — скрипты конвейера (извлечение, перевод, инжекция)
glossary/glossary.md — «библия перевода» (имена, фракции, сленг)
AGENTS.md            — техническая документация проекта
README.md            — этот файл
```

## Как технически устроена игра (для контрибьюторов)

Fallen Aces — **Unity**-игра с кастомным слоем данных в открытых **текстовых**
файлах. Весь текст лежит в `AcesData/` в форматах:
- **Субтитры:** `{ T 0.5 } "text"`, `T 0 "text"` (внутри `I N {}` блоков), просто `"text"`.
- **Записки:** `text = "..."` и `print_name = "..."` (с rich-text тегами `<color=#...>`).
- **Названия глав/эпизодов:** `title = "..."`, `description_text = "..."`.
- **Названия предметов:** `title = "..."`, `inGameName = "..."`.
- **Скрипты:** `SpeakDialogue(arg, "text")` — ссылается на субтитры по имени файла
  (поэтому имена файлов менять нельзя).

### Конвейер перевода (`tools/`)
1. `extract*.py` — извлечение строк из файлов с точными координатами.
2. `make_packs*.py` — деление на батчи для параллельного перевода.
3. Перевод (субагентами ИИ по глоссарию) → результат в `packs*/*.out.json`.
4. `inject*.py` — сборка переведённых файлов в `mod/` (замена только текста
   внутри кавычек; исходники берутся из бэкапа `Fallen Aces_backup_txt`).
5. `verify.py` / проверки — контроль кодировки, синтаксиса, полноты.

Перевод генерировался автоматически; если хочешь перегенерировать отдельную
поверхность — изучи `AGENTS.md` и скрипты в `tools/`.
