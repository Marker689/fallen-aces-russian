# Глоссарий перевода Fallen Aces («библия перевода»)

Этот документ — единый источник истины для всех субагентов-переводчиков.
**Любые упоминания персонажей, фракций, локаций и ключевых терминов ДОЛЖНЫ
переводиться строго по этому глоссарию, независимо от контекста.**

Сеттинг игры: нуар-детектив 90-х. Тон — грубоватый, ироничный, с чёрным
юмором, уличный сленг. Держать этот тон в переводе.

## 7. Правила перевода (обязательно для всех субагентов)

1. **Сохраняйте структуру и формат файла** — это критично. Меняйте ТОЛЬКО текст
   внутри кавычек `"..."`. Не трогайте тайминги (`T 0.5`), идентификаторы
   блоков (`I 0`), скобки, точки с запятой, теги `<color=#...>`.
2. **Имена собственные** — по глоссарию (раздел 1). Не транслитерируйте
   по-своему, используйте фиксированные варианты.
3. **Держите тон** — грубоватый нуар, сленг, ирония. Не делайте перевод
   «канцелярским» и слишком книжным.
4. **Rich-text теги** (`<color=#FFFFFF>`, `</color>`) оставляйте нетронутыми,
   переводите только текст внутри.
5. **Escape-последовательности** вроде `\n` или кавычек внутри строк — сохраняйте.
6. **Длина** — старайтесь не сильно превышать длину оригинала (важно для
   таймингов субтитров и вёрстки).
7. **Не добавляйте и не удаляйте строки** — число строк в файле должно остаться
   прежним.
8. Если сомневаетесь в переводе имени/термина — сверяйтесь с этим глоссарием.
   Если термина нет в глоссарии — переводите по смыслу и укажите его в ответе
   для добавления в глоссарий.
