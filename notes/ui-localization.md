# Локализация UI/меню — XUnity.AutoTranslator (ветка feature/ui-localization)

Этот документ описывает, как перевести **UI/меню/действия/имена врагов**, зашитые
в DLL игры, через рантайм-перехват **XUnity.AutoTranslator** (BepInEx 5 Mono).
Нарративный текст (субтитры/записки) уже переведён отдельно в `mod/` и ставится
прямой заменой файлов — см. основной README.

## Принцип

- XUnity.AutoTranslator перехватывает строки, которые игра передаёт текстовым
  компонентам (UGUI / TextMeshPro), и подменяет их по словарю.
- Сам DLL игры **не редактируется** — мод обратимо снимается.
- Словарь лежит в `BepInEx/Translation/ru/Text/*.txt` форматом `оригинал=перевод`.
- Онлайн-перевод (Google) служит только запасным вариантом; строки из словаря
  имеют приоритет.

## Что входит в дистрибутив UI-локализации (`mod_ui/`)

```
mod_ui/
  BepInEx/
    config/AutoTranslatorConfig.ini          # Language=ru, FromLanguage=en, EnableTextMeshPro=True
    Translation/ru/Text/ui_dictionary.txt    # словарь UI (копируется в игру)
  Fonts/DejaVuSans-Regular.ttf               # кириллический шрифт (только если нужен, см. ui-font.md)
  unity_font_build/                          # сборка TMP-шрифта в asset bundle (если нужен)
```

> BepInEx `core/` и `plugins/` (сам AutoTranslator/ResourceRedirector) ставятся
> из официальных zip-архивов и в `mod_ui/` не дублируются — оверлей `mod_ui/BepInEx/`
> содержит только конфиг и словарь, которые поверх уже установленного BepInEx.

## Установка (однократная, уже сделана в игре)

1. BepInEx 5 x64 (`BepInEx_win_x64_5.4.23.5.zip`) → распаковать в **корень игры**.
2. `XUnity.AutoTranslator-BepInEx-5.6.1.zip` → распаковать в корень игры.
3. `XUnity.ResourceRedirector-BepInEx-2.1.0.zip` → распаковать в корень игры.
4. Запустить игру один раз → создастся `BepInEx/config/AutoTranslatorConfig.ini`.
5. Отредактировать конфиг: `Language=ru`, `FromLanguage=en` (EnableTextMeshPro
   уже True). Готовый конфиг лежит в `mod_ui/BepInEx/config/`.
6. Положить `mod_ui/BepInEx/Translation/ru/Text/ui_dictionary.txt` в
   `BepInEx/Translation/ru/Text/` внутри игры.

## Проверка

Запусти игру и проверь, что переводится UI. Горячие клавиши AutoTranslator:
- **ALT+R** — перезагрузить словарь (после правки .txt, без перезапуска игры).
- **ALT+T** — переключить показ оригинала/перевода (для сверки).
- **ALT+U** — вручную запустить перевод выбранного текста.

Если русский текст **не виден** (квадратики/пустота) — не хватает кириллицы в
шрифте UI → см. раздел про шрифт ниже.

## Сбор новых UI-строк (для полноты геймплея)

Текст карты/журнала/заданий — это данные, а не строки DLL, поэтому он попадает
в словарь только когда соответствующий экран реально открыт в игре. Процедура
**сбора** (репроизводимая, автоматизирована в `tools/harvest_ui.py`):

1. Запусти игру и **открой** непереведённые экраны: карту, журнал задач, записки,
   инвентарь, магазины, все подменю настроек, экраны сохранения. Каждый раз
   AutoTranslator записывает встреченные строки в
   `BepInEx/Translation/ru/Text/_AutoGeneratedTranslations.txt`.
2. Закрой игру и запусти:
   ```bash
   python3 tools/harvest_ui.py
   ```
   Скрипт прочитает файл из папки игры, отбросит уже переведённое и выпишет
   **новые** строки в `mod_ui/harvest_candidates.txt` форматом `original=`.
3. Заполни переводы после `=` в `mod_ui/harvest_candidates.txt`.
4. Влей обратно в словарь:
   ```bash
   python3 tools/harvest_ui.py --merge
   ```
5. Скопируй обновлённый `mod_ui/BepInEx/Translation/ru/Text/ui_dictionary.txt` в
   игру и нажми **ALT+R**.

> **Важно (проверено по исходникам плагина):** XUnity пишет в
> `_AutoGeneratedTranslations.txt` только строки, которые **получили перевод**
> (из словаря или онлайн). Строка без перевода в этот файл не попадает. Поэтому
> для сбора НОВЫХ строк онлайн-перевод должен быть **включён** (`Endpoint` не пуст)
> — иначе непереведённые строки не запишутся. Словарь всегда имеет приоритет над
> онлайном, а задержки появляются только на строках, которых ещё нет в словаре
> (меню уже покрыто — там задержек нет). После сбора и влития строк в словарь
> онлайн можно снова отключить, если хочется совсем без сети.

## Шрифт (кириллица в UI)

Встроенные UI-шрифты игры, скорее всего, **не содержат кириллицы**. Решение —
подключить кириллический TMP Font Asset через конфиг:
- `FallbackFontTextMeshPro=` — путь/имя TMP-шрифта как запасной (не ломая основной);
- `OverrideFontTextMeshPro=` — полностью заменить шрифт на TMP-шрифт.

Подробная процедура создания TMP Font Asset — в `notes/ui-font.md`.

## Откат

Удалить папки `BepInEx/` и `winhttp.dll`, `doorstop_config.ini` из корня игры —
BepInEx и AutoTranslator снимаются полностью. Нарративный перевод при этом
остаётся (он в `AcesData`).
