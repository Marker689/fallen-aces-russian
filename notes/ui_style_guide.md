# Стиль-гайд перевода UI Fallen Aces (редакторский проход)

Этот документ — ОБЯЗАТЕЛЕН для всех переводчиков при редакторском проходе словаря.
Цель: превратить «васянский» машинный перевод в живой, естественный русский
с нуар-стилем 90-х.

## 1. Главная задача

Каждую строку словаря нужно **переписать так, как написал бы русский редактор
локализации**, а не как перевёл автомат. Убираем дословность, канцелярит,
неестественные обороты. Делаем живой, разговорный, стилистически точный текст.

## 2. Тон и регистр (НУАР 90-х)

Игра — нуар-детектив 90-х (грубоватый, ироничный, уличный сленг, чёрный юмор).
Требования к тону:
- **Живой, разговорный, но без панибратства.** Не канцелярский, не книжный.
- **Уместный сленг** (как в глоссарии: громила, легавый, мафиози, ствол, бабки).
- **Короткие, хлёсткие фразы** для HUD/подсказок — как в настоящих играх.
- Для предметов/интерфейса — **естественные русские названия**, не кальки.
- Ирония и чёрный юмор — только там, где это в духе игры (загрузочные шутки).

## 3. ЧТО УБИРАТЬ (признаки «васянского»)
- **Дословные кальки**: «Универсальная банка», «Общий контейнер», «Элементы
  управления по умолчанию» (это про настройки) → естественно: «Банка», «Ящик»,
  «Управление по умолчанию».
- **Канцелярит**: «Пользовательские сложности» → «Свои сложности» / «Настройка
  сложности». «Осуществляет» → «делает».
- **Буквальные глаголы** там, где в играх принято иначе: «unlocked» → «разблокировано»,
  «resume» → «продолжить».
- **Неестественный порядок слов** и слишком длинные обороты.
- **Одно и то же по-разному** — следи за консистентностью терминов.

## 4. Технические правила (НЕЛЬЗЯ НАРУШАТЬ)
Строка формата `original=translation`:
1. **`original` (слева от `=`) НЕ трогать вообще** — только правую часть (перевод).
2. В строке должен остаться **ровно один неэкранированный `=`** (разделитель).
3. **Плейсхолдеры** `{0}`, `{1}`, `${0}`, `${1}` — сохранить в том же порядке.
4. **Rich-text теги** `<color\=#...>`, `</color>`, `<u>`, `</u>`, `<br>` — сохранить
   как есть, включая экранирование `\=` (это `=` внутри тега, его экранируют).
   Переводить только видимый текст МЕЖДУ тегами.
5. **Escape-последовательности** `\n`, `\t` — сохранить как есть (это переносы/табы).
6. **Не менять число строк** — одна строка входа = одна строка выхода.
7. **Комментарии** (строки с `#`) и пустые строки — копировать без изменений.

## 5. Глоссарий (обязателен)
Сверяйся с `glossary/glossary.md`. Зафиксировано:
- Glassjaw→Гласджо, VISE→ВАЙЗ, Glasshearts→Глассхарты, Mook→Мушкетёр/головорез,
  Goon→Громила, Hideout→Притон, Nightwave→Найтвейв, Umburgh→Умбург,
  Gianni→Джанни, Marek→Марек, gumshoe→легавый.
- Названия клавиш: Space→Пробел, Tab→Tab, Ctrl→Ctrl, одиночные буквы W/A/S/D/E и
  т.п. остаются латиницей.

## 6. Примеры (как надо / как не надо)
| Плохо (васянски) | Хорошо |
|---|---|
| Не хватает наличных! | Бабла не хватает! / Нет наличных! |
| Игрок купил дорогой предмет | Куплен дорогой предмет |
| Нажмите [ ] для продолжения | Нажмите [ ], чтобы продолжить |
| Получено разрешение войти на территорию этой фракции! | Теперь ты свой в этой части города! |
| Использованный ключ от охранных ворот | Ключ от охранных ворот (использован) |

Не переусердствуй с жаргоном — тон должен быть «нуар-игра», а не «блатная
базарная тарабарщина». При сомнении — естественнее и короче.
