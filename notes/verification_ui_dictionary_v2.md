## 1. Проверка правил парсинга — ✅ PASS (0 проблем)

Прогон по всем 319 некоммент-строкам:
- **Ровно один неэкранированный `=` в каждой строке** — подтверждено для всех.
  Ни одна строка не будет молча отброшена плагином из-за `>1` разделителя.
- **Экранирование `\=` внутри rich-text тегов `<color=...>`** — присутствует во
  всех тегах (L57, 58, 81, 226–234, 276, 282, 316, 344, 346, 392, 394, 396–410,
  414, 438, 444). Ни одного неэкранированного `=` внутри тега не найдено.
- **Подозрительные escape** (backslash не перед `=`,`n`,`t`,`\`) — не найдено.
- **Плейсхолдеры `{0}`,`{1}`,`${0}`,`${1}`** — полностью сохранены во всех
  записях (в т.ч. L32, L47, L51, L226–233, L396–410).
- **`\n`/`\t`** — сохранены как есть.
- **Баланс rich-text тегов** (`<color>`/`</color>`, `<u>`/`</u>`) — сбалансирован
  во всех строках (исключая фрагмент L234, где открывающий `</color>` намеренно
  «оторван» — это кусок конкатенации игры, не ошибка).

## 4. Тон / регистр / естественность русского — несколько замечаний (MINOR)

### 4.1. Новые предметы (приоритет — собрано из игры)
Почти все переведены корректно и естественно:
`Generic Can→Банка`, `Cooking Pot→Кастрюля`, `Fridge Door→Дверца холодильника`,
`Cigarette Machine→Автомат с сигаретами`, `Sliding Door→Раздвижная дверь`,
`Pipe Wielding Mook→Головорез с трубой`, `Unarmed Goon→Безоружный громила`,
`Pickpocket→Карманник`, `Generic Container→Ящик`, `Button→Кнопка`,
`Chop→Рубить`, `Stomp→Затоптать` — приемлемо.

Замечания:
- **L434** `Used Security Gate Key=Использованный ключ от ворот` — «Security
  Gate Key» = «ключ от охранных ворот/шлагбаума», «Used» = израсходованный.
  Текущий вариант «Использованный ключ от ворот» читается коряво.
  → `Used Security Gate Key=Ключ от охранных ворот (использован)`
- **L446/444** `Vent=Вентиляция` — дословно; в контексте лаза/воздуховода
  естественнее «Вентиляционная решётка» / «Воздуховод». Приемлемо, но на грани.
  → (опц.) `Vent=Вентиляционная решётка`

### 4.2. Грамматика суффикса (Locked) — новые строки
- **L438** `Gate<color\=#ff0000ff> (Locked)</color>=Ворота<color\=#ff0000ff> (Заперто)</color>`
  — «Ворота (Заперто)» грамматически неверно (мн. число) → `(Заперты)`.
- **L444** `Vent... (Locked)=Вентиляция... (Заперто)` — неверный род → `(Заперта)`.
- **L412** `Locked!=Заперто!` — без существительного, нейтральная форма допустима. ОК.

### 4.3. Меню/журнал
- **L292** `KEY ITEMS=КЛЮЧЕВЫЕ ПУНКТЫ` — «пункты» (points) звучит неестественно
  для предметов → `КЛЮЧЕВЫЕ ПРЕДМЕТЫ`. (MINOR)
- **L244** `Custom=Своя` — см. §5.1 (консистентность).
- Остальное (`Resume→Продолжить`, `Back To Title→В главное меню`,
  `OBJECTIVES/NOTES/CLUES/MAPS`, `PAUSED`, `CHAPTER 1`, `PRIMARY/SECONDARY GOALS`,
  `«ПОБУДКА»`) — корректно и по регистру.

### 4.4. Прочие точечные (старые записи, но в зоне внимания)
- **L29** `You unlocked it=Вы открыли это` — «unlock» ≠ «открыть»;
  естественнее `Вы разблокировали это`. (MINOR)
- **L70** `Can't reload, hands are full=Не перезарядить, руки заняты` —
  коряво → `Нельзя перезарядить — руки заняты`. (MINOR)
- **L88** `Open Door Region=Открыть область двери` — буквально;
  → `Открыть дверную зону` / `Открыть дверь`. (MINOR)
- **L128** `Hostiles pacified=Врагов утихомирено` — «pacified» = усмирено
  (нелетально) → `Врагов усмирено`. (MINOR)

## 5. Консистентность — 2 замечания (MINOR)

### 5.1. Custom (L244) vs Custom Difficulties (L158)
- L158: `Custom Difficulties=Настраиваемые сложности`
- L244: `Custom=Своя`
Корень переведён по-разному. Рекомендуется унифицировать:
→ `Custom=Настраиваемая` (согласовано с «Настраиваемые»).

### 5.2. Отображение клавиши U
- Все одиночные клавиши латиницей (W,A,S,D,E,Q,R,F,G,X,Z,C,V,B,N,M — L360–390),
  а **L422** `У [Hold]=У [Удерживать]` содержит кириллическую «У». Это может
  означать, что игра в этом месте реально выводит «У» (тогда ок), либо ошибка
  харвестинга. Рекомендуется проверить в игре; при латинской клавише добавить
  `U [Hold]=U [Удерживать]`.

### 5.3. (справочно, не ошибка) дубли по кодировке таба
L223 и L242 — почти идентичные отладочные строки Unarmed Goon, но с разной
кодировкой таба (`\t` vs реальный символ). Это две разные ключи игры — обе
переведены согласованно, корректно.

## 6. Ключевые строки для ручной проверки в игре (харвестинг)
- **L400** `... Zoom Inp</color>` — в оригинале опечатка «Zoom Inp» (вместо
  «Zoom In»). Перевод `Приблизить` верен. Но запись сработает только если игра
  реально выводит «Zoom Inp». Если игра выводит «Zoom In», нужна дополнительная
  запись `... Zoom In</color>`.
- **L422** см. §5.2.
